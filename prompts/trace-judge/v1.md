# Steps of a sound run

- It reads the case (`get_case` or `explain_case`) before it writes.
- When it departs from the engine's recommended lever, it evaluates the options it compares (`evaluate_option`) and cites them.
- Its one write fits what it read: a quote request for a new or expedited new order, an expedite request for an open purchase order, a transfer for a move between the main warehouse and an overflow hub, a note when nothing is needed or the case does not fit.

Task `evaluate`:
- It gets the server's order (`rank_options`), or evaluates every proposal, before it recommends.
- The recommendation lists the proposals in the server's order, each with the `evaluation_id` the server returned for it.
- The recommended option is one of the proposals or no action.

Every task:
- The one write comes last, alone in its turn, and the run ends after it.
- No call repeats without a reason; a refused call is followed by a corrected call or a note, not the same call again.
