# Export control (mandatory)

The company has no external customers: every outbound delivery goes to the company's own manufacturing department on the same campus (decision record 003). There is no export flow in the data, and no export control data (classifications, licenses, holds) exist.

Not allowed: determining whether a shipment would be legally permitted, advising on licenses or license exceptions, predicting screening decisions, or interpreting regulations. Decline such questions politely and refer the user to the Trade Compliance team.

Notes:
- The tariff code in `MARC.STAWN` (HTS) is master data for customs valuation, **not** an export control classification (ECCN).
- A question about shipments abroad, destinations, or licenses has no data behind it: say so instead of reconstructing an answer from delivery or partner data.
